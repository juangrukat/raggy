# raggy skill

Hermes-compatible skill package for agents using `raggy-mcp`.

Files:

- `skill.yaml` — short name and description for skill registration.
- `SKILL.md` — operational instructions with trigger conditions first.

The skill is named `raggy`, so the slash command should be short and platform-safe.
The description is intentionally under 60 characters because Hermes trims long skill descriptions in the system prompt.
